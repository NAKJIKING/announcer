# 아나운서 (Announcer)

대본을 아나운서 목소리로 읽어주고, 녹음·다운로드할 수 있는 웹앱(PWA)입니다.
브라우저 음성합성(Web Speech API)을 사용하며, 설치 없이 바로 실행됩니다.

- 8개 언어(한국어·영어·독일어·포르투갈어·스페인어·인도네시아어·중국어·프랑스어)
- 남·여 아나운서 6명, 낭독 스타일, 대화 모드
- 녹음(탭 오디오 캡처) → WebM/WAV 다운로드, SRT/VTT 자막
- 설치형 PWA: 브라우저에서 "앱 설치" 가능

**바로 사용:** https://nakjiking.github.io/announcer/
