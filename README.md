# 아나운서 (Announcer)

대본을 아나운서 목소리로 읽어주고, 녹음·다운로드할 수 있는 웹앱(PWA)입니다.
설치 없이 바로 실행되고, 목소리 엔진이 **두 가지**입니다.

- **기기 음성** (기본) — 설치된 음성을 전부 목록에 띄웁니다. 즉시 쓸 수 있습니다.
- **AI 음성** (선택) — 온디바이스 신경망(Supertonic 3). 기기와 상관없이 같은 고품질
  목소리가 나오고, **오디오를 WAV 파일로 바로 저장**할 수 있습니다.
  처음 켤 때 약 105MB 를 한 번 내려받고, 그다음부터는 오프라인에서도 동작합니다.

기능

- 8개 언어(한국어·영어·독일어·포르투갈어·스페인어·인도네시아어·중국어·프랑스어)
- 세 가지 모드 — **대본**(문장 하이라이트 낭독) · **단어**(여러 목소리 비교·느리게·반복) ·
  **긴 글**(조각마다 합성하며 재생, 전체 WAV 저장)
- AI 목소리 10종 + **두 목소리를 섞어 새 목소리 만들기**
- 낭독 스타일, 대화 모드, 발음 사전, 속도·음높이 조절
- 녹음(탭 오디오 캡처) → WebM/WAV 다운로드, SRT/VTT 자막
- 설치형 PWA: 브라우저에서 "앱 설치" 가능

> 중국어는 AI 음성이 지원하지 않아 기기 음성으로 읽습니다.

### 라이선스

생성된 음성 파일은 자유롭게 쓸 수 있습니다. 다만 AI 음성 모델은 **OpenRAIL-M**
(Supertone Inc.) 이라 **사용 제한**이 있습니다 — 특히 동의 없이 특정인의 목소리를
흉내 내는 데 쓸 수 없습니다. 전문은 앱의 *정보 · 라이선스* 패널에서 볼 수 있습니다.
추론 코드와 실행기(onnxruntime-web)는 MIT 입니다.
